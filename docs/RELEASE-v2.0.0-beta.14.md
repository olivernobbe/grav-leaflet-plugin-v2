# Map Marker Leaflet V2 — 2.0.0-beta.14

## Mapbox logo background

Make the CSS background behind the Mapbox logo transparent. Keep the official
SVG asset unchanged and retain its 81 × 20 px display size. This prevents the
white rectangular control background from appearing over the map while keeping
the Mapbox logo visible.

## Update

The update archive contains only files changed since beta.13. Replace those
files in the existing `map-marker-leaflet-v2` plugin folder and clear Grav's
cache. The plugin configuration does not need to change.
