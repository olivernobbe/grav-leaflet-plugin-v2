# Map Marker Leaflet V2 — 2.0.0-beta.15

## Third-party marker asset notices

The distribution retains legacy image files from Leaflet.ExtraMarkers v1.1.0
and Leaflet.awesome-markers. Although V2 does not reference these images during
normal rendering, both sets remain in the plugin's assets directory. This
release includes their MIT copyright notices, license terms, asset mapping, and
source links in `assets/THIRD-PARTY-MARKER-LICENSES.txt`.

The existing plugin MIT notice and Leaflet BSD-2-Clause license remain included.

## Update

The beta.15 update archive contains only files changed since beta.14. Upload the
files to the existing `map-marker-leaflet-v2` plugin folder and clear Grav's
cache. No plugin configuration changes are required.
